# التورنتات المخفية في Nyaa ← تيلغرام

يفحص هذا المستودع nyaa.si كلّ 3 ساعات على خوادم GitHub Actions (لا يحتاج إلى جهازك)،
ويرسل كلّ تورنت مخفيّ جديد إلى بوت تيلغرام ‎@Nyaahiddenbot‎.

- **السكربت:** `nyaa_hidden_torrents.py`
- **الجدولة:** `.github/workflows/scan.yml` (كلّ 3 ساعات في الدقيقة 17، وقد يتأخّر GitHub دقائق).
- **البيانات:** `archive.json` (الأرشيف)، `state.json` (آخر نقطة وصل إليها الفحص وما بقي منه)،
  و`التورنتات المخفية.html` (القائمة؛ نزّلها وافتحها في المتصفّح). يحدّثها الفحص بنفسه.
- **الأسرار:** `TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID` في Settings ← Secrets and variables ← Actions.

**تشغيل فوريّ:** تبويب Actions ← Scan nyaa hidden torrents ← Run workflow (واختر test_notify لإرسال رسالة اختبار فقط).
**الإيقاف:** تبويب Actions ← Scan nyaa hidden torrents ← ⋯ ← Disable workflow.

الرصيد المجّانيّ للحساب نحو 2000 دقيقة في الشهر لكلّ المستودعات الخاصّة معًا. هذا الفحص يستهلك نحو 250 دقيقة شهريًّا،
ولا يتجاوز 500 في أسوأ الأحوال: 8 تشغيلات يوميًّا، وكلّ فحص محدود بدقيقة واحدة ويُكمل ما بقي في التشغيل التالي.
