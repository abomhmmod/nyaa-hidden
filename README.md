# التورنتات المخفية في Nyaa ← تيلغرام

يفحص هذا المستودع nyaa.si كلّ 30 دقيقة على خوادم GitHub Actions (لا يحتاج إلى جهازك)،
ويرسل كلّ تورنت مخفيّ جديد إلى بوت تيلغرام ‎@Nyaahiddenbot‎.

- **السكربت:** `nyaa_hidden_torrents.py`
- **ملفّ التشغيل:** `.github/workflows/scan.yml`
- **البيانات:** `archive.json` (الأرشيف)، `state.json` (آخر نقطة وصل إليها الفحص وما بقي منه)،
  و`التورنتات المخفية.html` (القائمة؛ نزّلها وافتحها في المتصفّح). يحدّثها الفحص بنفسه.
- **الأسرار:** `TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID` في Settings ← Secrets and variables ← Actions.

## كيف يتكرّر الفحص

جدولة GitHub (cron) لا يُعتمد عليها وحدها: لم تعمل في هذا المستودع منذ إنشائه، وهي تُسقط كثيرًا من مواعيدها. لذلك للفحص مصدران:

1. **الإيقاظ الذاتيّ (الأساس):** كلّ تشغيل ينتهي بمهمّة اسمها `wake`. تنتظر 30 دقيقة ثمّ تطلب التشغيل التالي. والانتظار لا يشغل خادمًا.
2. **جدولة GitHub (احتياط):** كلّ 3 ساعات. فإن انقطعت السلسلة لأيّ سبب أعادتها.

- إن بدأ تشغيل أحدث أثناء الانتظار فهو الذي يُكمل، فتبقى سلسلة واحدة ولا يتكرّر الفحص.
- إن تعذّر طلب التشغيل التالي، يرسل البوت تنبيهًا إلى تيلغرام.
- **تغيير المدّة:** Settings ← Environments ← `wake-30` ← Wait timer. ولا تجعلها أقلّ من 5 دقائق، فصمام الأمان في ملفّ التشغيل (`MIN_AGE`) يرفض ما دونها.

## الاستعمال

- **تشغيل فوريّ:** تبويب Actions ← Scan nyaa hidden torrents ← Run workflow (واختر test_notify لإرسال رسالة اختبار فقط).
- **الإيقاف:** تبويب Actions ← Scan nyaa hidden torrents ← ⋯ ← Disable workflow.
- **إعادة التشغيل بعد الإيقاف:** Enable workflow، ثمّ Run workflow مرّة واحدة لتبدأ السلسلة من جديد.

## الاستهلاك

المستودع عامّ، وتشغيل المستودعات العامّة مجّانيّ ولا يُخصم من رصيد الدقائق.

**تنبيه:** مؤقّت الانتظار الذي يقوم عليه الإيقاظ الذاتيّ لا يتوفّر للمستودعات الخاصّة في الخطّة المجّانيّة.
فإن أُعيد المستودع خاصًّا توقّف الإيقاظ الذاتيّ (ويرسل البوت تنبيهًا بذلك)، ولزم بديل:
خدمة جدولة خارجيّة مثل cron-job.org تطلب التشغيل في مواعيده.
